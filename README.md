# Cavendish International Hospital Management System

A full-stack Hospital Management System built with **PHP, MySQL, HTML5, CSS3, JavaScript, and Bootstrap** for managing hospital operations including patients, doctors, appointments, pharmacy, billing, and reports.

## 🏥 Project Overview

The Cavendish International Hospital Management System is a web-based healthcare management platform designed to digitize hospital workflows and improve communication between patients, doctors, pharmacists, and administrators.

The system provides different dashboards and tools based on user roles.

## 🚀 Main Features

### 👨‍💼 Admin Dashboard

- Manage patients
- Manage doctors
- Manage staff accounts
- Manage appointments
- Manage pharmacy inventory
- Manage billing and payments
- Generate reports
- Monitor hospital activities

### 👨‍⚕️ Doctor Portal

- Doctor login
- View assigned patients
- View appointment requests
- Accept or update appointments
- Manage consultations
- Add diagnoses
- Create prescriptions
- View patient medical records

### 🧑‍🤝‍🧑 Patient Portal

- Patient registration
- Patient login
- Book appointments
- View appointment status
- View medical records
- View prescriptions
- Receive notifications

### 💊 Pharmacy Module

- Manage medicines
- Add new medicines
- Update medicine stock
- Track prescriptions
- Monitor inventory
- Manage medicine categories

### 💰 Billing Module

- Generate invoices
- Track payments
- Manage hospital charges
- View billing records
- Generate financial reports

### 📊 Reports

- Patient reports
- Doctor reports
- Appointment reports
- Pharmacy reports
- Billing reports
- Hospital activity reports

## 🛠 Technologies Used
